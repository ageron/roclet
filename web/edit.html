Format playground ↗

Escape selects a cell. Arrow keys move between cells; Shift plus arrows extends the selection. Enter edits. Use your usual copy, cut and paste shortcuts for selected cells.

Multiple cursors edit within one cell. Shift extends text selections without leaving the cell. Vertical motion keeps its intended column across shorter lines and cells.

Click a cell number to select it; Shift-click to select a range. Open ⋯ on any selected cell to move, collapse/expand, or merge the group. Click prose to edit Markdown. Tab moves between controls; it indents in an editor. Press Esc first to navigate controls.

Export & share



Roclet bundles include the source, cell structure, and compiler identity. Open them in a compatible version of Roclet. Reports open directly in a browser. Interactive sites include Roclet and the compiler for hosting on HTTPS or localhost. Existing saved-output comments stay part of the source. Nothing is uploaded.

Roc downloads are runnable scripts. Rich outputs use a pinned Display package, which Roc downloads automatically. Roclet supplies it offline.
