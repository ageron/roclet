Install the Roclet server

Most people can use Roclet in their browser without installing anything. The optional server runs a local copy of the same app. No Roc or Zig installation is needed.

1. Download and extract

Open GitHub releases and choose a Roclet server release, then download the archive for your computer.

ComputerArchive
Mac · Apple Siliconroclet-macos-arm64.tar.gz
Mac · Intelroclet-macos-x64.tar.gz
Windows · x64roclet-windows-x64.zip
Linux · x64roclet-linux-x64.tar.gz
Linux · ARM64roclet-linux-arm64.tar.gz

Extract the archive and keep the resulting roclet folder somewhere permanent. Keep the executable and its folders together.

2. Start Roclet

Open a terminal in the extracted folder. On macOS or Linux:

./roclet

On Windows, in PowerShell:

.\roclet.exe

Open http://127.0.0.1:4173/. Keep the terminal running; press Ctrl+C to stop the server. If the port is busy, use --port 4174.

Optional: use the roclet command anywhere

Add the extracted folder to your PATH. On macOS or Linux, add this line to your shell configuration (such as ~/.zshrc or ~/.bashrc), replacing the path:

export PATH="/absolute/path/to/roclet:$PATH"

On Windows, search for Edit environment variables for your account, edit your user Path, and add the extracted folder. Open a new terminal, then run roclet.

The server serves the browser app; it does not run notebooks headlessly. For development and the separate headless runner, see the source build instructions.
