    What can you use it for?

    Learning Roc
    Try expressions, inspect results, and keep notes next to the code.
    Learning interactively
    Explain a concept with text, equations, and code that readers can change.
    Data exploration
    Transform data and compare results as you refine your calculations.
    Exploring Roc packages
    Import a package and try its functions in a notebook, with examples you can save and share.
    Literate programming
    Keep explanations beside production code and save the notebook as a runnable Roc script.

    Planned platforms

    We plan to add Roclet platforms for specific uses, such as turtle graphics for teaching programming and tools for creating and testing web services. Each platform would provide the capabilities and interface that suit the task.
